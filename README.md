Quick Check is a responsive web application that combines a Calendar, Weather Dashboard, and To-Do List — helping users plan, track, and stay updated in one clean interface. Built using HTML, CSS, JavaScript, and public APIs, it delivers a seamless personal productivity experience with real-time data and a minimalist design.

🚀 Features

📅 Smart Calendar – Displays the current date and day with a neat, responsive layout.

🌤️ Live Weather Widget – Fetches real-time weather data using an external API (temperature, condition, and location).

To-Do List Manager – Add, delete, and check off tasks to stay organized.

Fully Responsive – Optimized for desktop, tablet, and mobile devices.

API-Driven – Integrates weather and time APIs for dynamic, up-to-date information.

Tech Stack

Frontend: HTML, CSS, JavaScript

APIs Used: Weather API, Date/Time API

Design: Responsive UI with clean and minimal styling
